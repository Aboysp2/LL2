# لاباركوه للغات Pro
تحديث شامل لتطبيق تعلم الفرنسية للناطقين بالعربية.

## ما تم تطويره
- واجهة PWA حديثة ومتجاوبة للهاتف والويب.
- مسار A1 → B2 مع الدروس الموجودة.
- مختبر تدريب: بطاقات مفردات، اختيار سريع، الأبجدية، القواعد.
- فرنسية الحياة اليومية والعملية: المطار، الطبيب، العمل، التسوق.
- لوحة تقدم، XP، سلسلة أيام، مهام يومية.
- نطق فرنسي عبر Speech Synthesis.
- قاموس وبحث ومحتوى قراءة/قصص/حوارات واختبار نهائي.
- حفظ التقدم محلياً ودعم العمل دون اتصال عبر Service Worker.

## التشغيل
افتح `index.html` مباشرة أو انشر المجلد على GitHub Pages / Netlify / Vercel.
لأفضل تجربة PWA استخدم HTTPS عند النشر.
